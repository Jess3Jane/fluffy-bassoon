# Fluffy Bassoon

A project all about letting you build something with very little direction.

## What you're building

A complex simulated world. Emergent complexity is the name of the game.

## How you'll do it

When you start up, pick a task off TASKS.md. If there are no tasks, figure out
the logical next step and add it. If a task is too complex, break it down into simpler tasks.

## The stack

The application must run in a web browser and be deployed via Github pages.

## Safety

You are the only one with access to this repo and it is fully private. You cannot do wrong. Move without fear,
be creative!
